Git 操作

准备就绪。点击任意命令播放动画。
提示：选择 (new file) 可以看到新文件回到 Untracked 区域。
教学说明：变更块的移动是概念动画。Git 实际维护工作区、Index 和 HEAD 中的文件版本。
TRACKED 与 UNTRACKED 同属工作区（Working Directory），由半透明框围起。
同一变更是一块长方体，先出现在源容器内部，再流入目标容器内部；外观会变：Untracked 灰色、Tracked 红色、Staging 黄色、Local Repo 绿色。
点击顶部 Demo 可连续观察新文件 git add 后再 git restore --staged 回到 Untracked。
“直接提交”使用 git commit -a，仅处理已跟踪文件。
reset --soft 保持 Index 和工作区不变；reset --mixed 重置 Index，保持工作区不变。
演示假设：reset 作用于最近一次提交，且工作区没有其他干扰性修改。
新文件示例： echo hello > new.txt; git add new.txt; git commit -m add; git reset --mixed HEAD~1 → new.txt 再次 untracked（前提是目标提交没有它）。
